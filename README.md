# 💰 Personal Expense Tracker (INR)

A clean, modern, and fully responsive **Personal Expense Tracker** built with standard HTML5, CSS3, and Vanilla JavaScript (ES6+). Track your daily income, manage expenses in Indian Rupees (₹), and view category breakdown charts without relying on external JS frameworks.

---

## ✨ Features

- **Financial Overview:** Real-time summary cards displaying Total Income, Total Expenses, and Net Balance formatted in INR (`₹`).
- **Full CRUD Support:** Add, edit, and delete income and expense transactions.
- **Local Storage Persistence:** Keeps data stored safely in the browser even after page refresh.
- **Visual Analytics:** Custom progress bars dynamically calculating category spending percentages using pure CSS/JS.
- **Category Filtering:** View transactions filtered by category (Food, Travel, Shopping, Bills, Salary, Freelance, Other).
- **Responsive Layout:** Responsive CSS Grid/Flexbox design optimized for mobile, tablet, and desktop viewports.
- **Input Validation & Feedback:** Form input verification with alert toast messages.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom CSS variables, Flexbox, Grid layout, smooth hover states, and animations.
- **JavaScript (ES6+):** Vanilla JS DOM manipulation, LocalStorage API, and `Intl.NumberFormat` for INR currency support.
- **FontAwesome:** Icons for UI visual enhancement.
